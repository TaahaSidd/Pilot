Documentation

Welcome to Pilot. This guide will walk you through deploying and configuring the browser automation engine in less than two minutes, executed entirely out of your native terminal window.

Pilot navigates course material dashboards autonomously, handles read-through blocks for baseline context compilation, and processes complex assessment arrays utilizing highly optimized Llama 3.3 70B models over Groq Cloud infrastructure.

Uses of Pilot

Pilot is engineered to abstract away repetitive administrative patterns across your student dashboard. It redirects manual, time-sink operations into automated pipelines so you can concentrate on high-priority development and learning objectives.

Asynchronous Course Progression

Eliminate manual multi-clicking. Pilot takes care of navigating linearly through extensive course layout structures, reading assignments, and informational pages on your behalf.

Context-Aware Assessment Operations

Instead of copying questions one-by-one, Pilot reads active quiz screens, structures the variables into data formats, and queries them against an optimized AI core to secure swift solutions.

Administrative Survey Resolution

Bypass unskippable system gates. Pilot autofills repetitive mid-module satisfaction cards, region queries, and feedback boxes so subsequent reading blocks unlock instantly.

Prerequisites

To run Pilot successfully, you must provide your own API keys and platform access details. Gather the following items before starting the execution script:

1. Amity Amigo Credentials

You need your official Amity University student email identifier (e.g., your.name@s.amity.edu) and corresponding portal password. Pilot uses these parameters to authenticating sessions smoothly inside Playwright core.

2. Groq API Access Key

Pilot handles evaluation queries using your personal model operational limits. Generate a functional application secret via your account dashboard.

Get Key from Groq Console →

3. Python Environment

Verify that your host machine has a clean distribution of Python 3.8 or higher fully initialized and registered to your local system console pathway mapping array.

Quick Start Guide

Forget handling hidden environment configuration files or leaving plain-text keys exposed on your local drive storage. Pilot prompts you interactively within your execution process console stream.

Step 1: Fetch Project & Environments

Launch your terminal environment and input the subsequent deployment blocks to set up the workspace repository and install core packages:

Terminal Console
# Clone the source repository
git clone https://github.com/TaahaSidd/Pilot.git

# Step directly into the working directory root
cd Pilot

# Install core interface, engine dependencies, and browser binaries
pip install -r requirements.txt
playwright install chromium

Step 2: Trigger the Engine

Launch the root initialization routine to spin up the automation loop wrapper:

Terminal Console
python main.py

Step 3: Direct Console Authorization

Provide your unique token and Amigo portal details directly into the terminal window when prompted by the application script:

The Automation Workflow

Once initialization clears, the task automation routine processes target user curriculum structures through a smart execution pipeline:

1. Target Evaluation

Pilot cross-examines the course listing indexes and skips 100% completed materials, focusing processing time only on active sections.

2. Context Aggregation

During textbook reading passes, Pilot scrapes text representations straight into short-term execution memory matrices to feed context data into subsequent quizzes.

3. Relational Multi-Pass Loops

Since progression configurations routinely gate subsequent tests behind prior items, Pilot loops through execution pipelines up to 10 distinct iterations to handle elements as they unlock.

Smart QuizSolver

The internal QuizSolver reads multiple-choice options on your screen, parses layout trees into structural evaluation syntax maps, and ships them directly to the ultra-fast Groq framework executing Llama 3.3 70B models.

Fail-Safe Grade Guardrails: Academic progress remains fully protected. If Pilot encounters custom layout styles it can't clear, or spots blank questions on a page, it stops processing to prevent faulty answer sets from hurting your grades.

Feedback Engine

To prevent progression locks due to mandatory survey fields, the integrated FeedbackSolver automates standard rating systems cleanly:

  • Enforces standard system location inputs across country and region selectors.
  • Fills matrix choice loops safely using high tier review numbers (9/10 fields).
  • Populates open textbox components using human-like, realistic strings to satisfy system minimum character criteria.
