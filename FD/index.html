Fast, accurate quiz resolution

Pilot reads the active quiz screen and passes question + context from the current reading material into Groq's Llama 3.3 70B. Responses come back in ~240ms.

Built-in guardrails halt submission if questions are malformed or layouts don't match expected patterns protecting your grades.

Gated content? It loops through.

Many Amigo courses lock modules behind prior completions. Pilot's loop engine runs up to 10 consecutive passes per session, picking up newly unlocked content on each cycle.

Feedback forms, mandatory surveys, and rating blocks are filled automatically so nothing gets stuck.

Your credentials never touch disk

No .env files, no config storage, no plain-text anything. Pilot prompts you at runtime and keeps everything in volatile session memory gone the moment the process ends.

Runs entirely on your local machine inside a real Chromium browser. Nothing is sent to external servers except your Groq API calls.

Common questions

What is Pilot?+
Pilot is an open-source browser automation tool built specifically for Amity Online students. It uses Playwright to control a real Chromium browser and Groq's Llama 3.3 70B to process quizzes automating the repetitive clicking, module navigation, and quiz workflows inside the Amigo portal.
Do I need a Groq account?+
Yes. Pilot uses Groq Cloud for AI inference. You'll need a free Groq account to generate an API key. Get one at console.groq.com it's free and takes about 30 seconds.
Is my password stored anywhere?+
Pilot saves your credentials locally on your machine in a config file so you only need to enter them once. They are never sent to any external server only your Groq API key is used for quiz inference via Groq Cloud. You can reset credentials anytime from the Settings menu.
What Python version do I need?+
Python 3.8 or higher. Run python --version to check. Install dependencies with pip install -r requirements.txt then playwright install chromium.
Will it hurt my grades?+
Pilot has built-in guardrails. If the QuizSolver encounters a malformed question, blank fields, or an unrecognized layout, it halts submission rather than submitting a bad answer. It won't guess blindly.
Does it work on Windows / Mac / Linux?+
Yes. Pilot is a Python script and runs wherever Python and Playwright are supported which includes Windows, macOS, and Linux.
