What is Pilot

Pilot is a narrow automation agent built for one platform: the Amity Amigo learning portal. Instead of dealing with repetitive interface navigation, Pilot automates your workflows locally by handling your common tasks directly through code: parsing course modules, solving internal validation checkpoints with LLMs, and checking off pending forms completely behind the scenes.

Capabilities

Short, concise and built for intent.

Everything you need to automate your local dashboard interactions without the architectural noise.

Course Discovery

Scans the home dashboard automatically, reads raw completion data metrics directly from interface containers, and cleanly filters out modules hitting 100 percent completion scores.

Local Security

Keeps your records and setup preferences stored inside local files on disk. Zero external data transmission beyond core API calls.

Feedback Forms

Locates and maps layout structures across dropmenus, standard input tags, and checkboxes, dynamically selecting structural options for seamless programmatic submission runs.

Quiz Resolution

Pipes actual page text contexts along with question payloads straight into premium reasoning instances, running structural option selections in direct parallel speeds.

FAQ
How does Pilot pass credentials securely?

Pilot uses a local environment file on your computer. Your username and password never leave your machine or pass through proxy servers—they are supplied directly to your local Chromium driver.

Does this require a paid LLM API key?

No. By default, Pilot connects to Groq API using free tier keys to query open-weights models like Llama 3.3, delivering low-latency inference speeds at zero operational cost.

Can it run undetected on the portal?

Pilot uses realistic user-agent profiles, dynamic delays between button interactions, and human-like movement sequences to remain within standard system usage boundaries.

What happens if an LLM answers a quiz incorrectly?

Pilot runs structural checks on form submissions. If an evaluation iteration falls below threshold metrics, the session saves local contextual states, allowing you to manually override or re-run specific blocks from the CLI engine.

How does the agent handle sudden portal UI layout updates?

Instead of relying strictly on hardcoded XPath positions, Pilot matches data targets based on resilient structural markers and relative text anchors, keeping the local workflow engine stable when minor layout variations shift.
